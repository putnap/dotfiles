Neovim stays out of the Ctrl+Shift set. herdr takes those keys before any program in a pane sees them, which is wanted: sometimes you want a new editor window, sometimes a new terminal. Splitting a pane and splitting a buffer look alike but are different objects.

06The model

One modifier per app. The same keys across apps. Where two apps do the same thing and cannot collide, they get the same chord — not merely the same letter.

ModifierOwnerMust be unique?
Alt, ⌘⌥Aerospaceyes — global
Ctrl+ShiftZen and the terminal stackshared
Ctrl+\ prefixherdrterminal only
SpaceNeovimterminal only
Ctrl+letter, Alt/Ctrl+arrowsText editingowned by no app

Aerospace is the only layer that has to be unique, because it grabs keys globally — whatever it claims is gone everywhere. Zen and the terminal never receive the same keystroke, so they share.

07Decisions

DecisionWhy
Aerospace moves, never the othersIt grabs keys globally and is indifferent to which modifier it gets. Zen is fussy; the terminal has its own constraints.
Alt+digit is never boundThe Lithuanian layout puts numbers on Alt+1–=, which also rules out - and = on bare Alt.
Resize lives on ⌘⌥+arrowsEvery other arrow combination is text editing: Alt is word motion, Shift is selection, Alt+Shift is word-selection, Cmd is line and history.
Ctrl+W stays delete-word in the terminalzsh, Claude Code and lazygit all bind it. A typing reflex must not be able to destroy a pane.
Close keeps each surface's own keyNo letter is free: w means window in Vim and tmux, d is delete but prefix+d is detach, q quits the whole app in a GUI, x is cut.
Neovim is not in the Ctrl+Shift setherdr eats those first, and that is wanted — a new editor window and a new terminal are different things.
No modes in AerospaceWindow moves are fast and reversible, not staged. Both binding modes were deleted.
Ctrl+A is line start experimentCosts Linux/Windows compatibility, where it selects all. Reverting is one Karabiner rule and one Neovim map.

08Blocks we hit

Each of these cost a wrong turn. They are the reason a binding can look perfect in a config and do nothing.

BlockWhat it means
Zen matches the shifted glyphWith Shift in the chord, record what the event carries: \→|, -→_, =→+, u→U. Recording the unshifted key stores a shortcut that never fires. This one insight unblocked the whole browser.
The terminal will not deliver Ctrl+Alt+letterNor Ctrl+Tab. It does deliver Ctrl+letter, Ctrl+Shift+letter, Ctrl+Shift+punctuation, Ctrl+Shift+arrows and Shift+arrows.
Alt+Shift is dead in ZenDiscovered after four bindings had been moved onto it. Test a modifier with one binding before moving a set.
optional: ["any"] passes modifiers throughIn Karabiner, Ctrl+Shift+T against a control+t rule emits Cmd+Shift+T, not Cmd+T. Getting this backwards ruled out a whole modifier for no reason.
There are layers below the config⌥⌘+B is Firefox's bookmarks, ⌥⌘+D is macOS's Dock toggle. Neither appears in any file you can read.
A collision in a file is not a bugZen beats macOS Hide Others on ⌥⌘+H but loses to view-source on ⌥⌘+U. Only pressing the key tells you.
herdr plugins must be linkedherdr plugin link <path>. Files in local-plugins/ do nothing until then, and herdr config check will not mention it — herdr plugin list will.
Direct chords are taxed from every TUIAnything herdr binds without the prefix is gone from lazygit, yazi, btop, hunk and Claude Code. Prefer the prefix; spend direct chords deliberately.
Most "broken" keys were never loadedZen unsynced, Ghostty running stale config, a Lua error aborting the rest of the file. Ask "is it live?" before "is it wrong?".

09Ideas and open questions

Worth trying

A held Karabiner layerThe only route to vim b/w/e in a GUI text field. Not modal — live only while held. Test on Ctrl+Space first.
Fast layout switchingStill unsolved. Caps held could toggle input source while a tap stays Escape.
Drop more prefix+ShiftSeveral already have unshifted aliases: rename tab is prefix+,, rename workspace prefix+$, swap panes prefix+{ and }.

Cannot be done

Zen split focus and resizeNo such action exists in its shortcuts file — only create, grid and unsplit.
Aerospace key repeatIts hotkeys fire once per press; there is no repeat or hold setting. A larger step is the only lever.
Unifying Ctrl+CSIGINT in a terminal, copy everywhere else. Ghostty's copy-on-select covers it.

Untested

tmux has been mirrored throughout but never run — the lazygit popup and the resize change are unverified there.
